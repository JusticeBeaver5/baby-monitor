# Camera Room — Netlify + HTTPS + Audio

Веб-приложение для передачи камеры **и микрофона** с одного устройства на другое через WebRTC.

- Netlify отдаёт сайт по HTTPS.
- PeerJS Cloud используется для установления WebRTC-соединения.
- Видео и аудио передаются между браузерами по WebRTC; приложение не загружает медиапоток на Netlify.
- Код комнаты — 6 символов и копируется одним нажатием.
- Полная локализация интерфейса: русский / английский.
- Язык сохраняется в `localStorage`.
- На стороне зрителя есть кнопка включения/выключения звука и полноэкранный режим.

## Деплой через Netlify Drop

1. Откройте https://app.netlify.com/drop
2. Перетащите **папку `camera-room-netlify` целиком**.
3. Откройте полученный `https://...netlify.app` адрес на двух устройствах.
4. На первом нажмите **Создать комнату / Create room**, разрешите камеру и микрофон.
5. Скопируйте код комнаты и введите его на втором устройстве.
6. Если звук не воспроизводится автоматически на iPhone, нажмите **Включить звук / Enable sound**.
7. Переключение языка — кнопка `EN` / `RU` в правом верхнем углу.

## Важно

Для разрешения камеры и микрофона нужен защищённый контекст, поэтому используйте HTTPS-адрес Netlify.

PeerJS Cloud отвечает за сигналинг. Для некоторых сетей прямое P2P-соединение WebRTC может не установиться без TURN-сервера. Для публичного/массового использования лучше добавить собственный TURN и при необходимости собственный PeerServer.


## Обновление интерфейса камеры

- Превью фронтальной камеры зеркальное, как у селфи.
- Превью задней камеры не зеркалится.
- Удалённое видео не зеркалится.
- Видео теперь использует `object-fit: contain`, поэтому весь кадр помещается без обрезания.
- Соотношение сторон окна просмотра подстраивается под фактическое видео.
